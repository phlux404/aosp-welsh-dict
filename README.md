# Welsh (cy) main dictionary for AOSP keyboards — FUTO / HeliBoard

The first main Welsh dictionary for the AOSP keyboard ecosystem.

Before this, Welsh in Helium314's `aosp-dictionaries` hub — the community
dictionary hub FUTO Keyboard's own docs point users to — existed only as an
**emoji** dictionary (9,171 entries, checked 2026-11-01). There was no main
dictionary: no word prediction, no autocorrect vocabulary for Welsh in FUTO
or HeliBoard. This fills that hole.

## Files

- `main_cy.dict` — compiled AOSP dictionary (284,439 bytes, sha256
  `6a241693d69935fc3d9b5695817b74957f610af2a819694495191264c71e8acf`)
- `cy_wordlist.combined` — source wordlist, 41,239 entries + header
  (sha256 `f1e300a4830cb286e742c834d3d1d05fad67b599729912400feff3c8663d0779`)
- `gen_combined.py` — generator: recounts the cywiki corpus sample used by
  the AnySoftKeyboard Welsh pack, log-scales frequencies onto the AOSP
  0–255 ladder, and overlays the hand-tuned spoken layer by max-merge.

Header: `dictionary=main:cy,locale=cy,description=Welsh,version=55`
(version > 18, as required for compatibility with all AOSP keyboards).

## How it was built — and the lesson baked in

Frequencies run 0–255 in AOSP format, like AnySoftKeyboard's. The first
AnySoftKeyboard build scaled corpus frequencies *linearly*, which squashed
everyday words to near-zero and buried them under place names. This build
uses a log ladder (18 points per decade of corpus frequency, floor 20,
ceiling 215 for corpus words) from the start, then lays the 517-entry
hand-tuned spoken layer from `phlux404/ask-welsh-pack` over the top at full
strength — contractions and the full Welsh mutation system for everyday
nouns:

- `dwi'n` f=255, `diolch` f=250, `mawr` f=246, `fawr` f=244
- `cath` f=205 → `gath` / `nghath` (f=170) / `chath` paradigm present
- `yng Nghymru` mutation forms present
- `Ngheri` — the place name AnySoftKeyboard kept autocorrecting *nghath*
  into — is **not in this dictionary at all** (below the frequency floor)

## Install in FUTO Keyboard

1. Download `main_cy.dict`
2. FUTO Settings → Languages & Models → add Welsh (cy) if not present
3. Welsh → Dictionary → import `main_cy.dict`

## Test sentences

Type these cold and watch the suggestion bar:

1. `Dwi'n byw yng Nghymru`
2. `Fy nghath i a dy gath di` — the sentence that broke the ASK pack
3. `Bore da, diolch yn fawr`
4. A sentence with ŵ / ŷ (e.g. `Mae'r dŵr yn y tŷ`)
